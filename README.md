# chat app 
#### app for real time communication with your friends 

---
# Setup and Installation 
### installation steps  
1. clone the repo
``` bash
    git clone https://github.com/Salah-T480/chat-app.git
    cd chat-app
```
2. install the dependencies for the frontend 
```bash
    cd client
    npm install
```
3. install the dependencies for the backend 
```bash
    cd ..
    cd server
    npm install
```
### run the app 
1. run the frontend server 
```bash
    cd ../client 
    npm run dev
```
the frontend will be at http://localhost:5173/

2. run the backend server
```bash
    cd ../server 
    npm run dev 
```
the backend  server will on http://localhost:5000

### how to start communication 
1. open http://localhost:5173/
2. enter your username
3. enjoy
